# Mapa Comunitário

Mapa interativo de problemas urbanos e ambientais (alagamentos, lixo, buracos)
no entorno da EREM Desembargador Renato Fonseca, em Olinda-PE, com uma rota
sugerida segura até a escola (rota e local exemplar. Passo futuro: sistema de GPS que calcula automaticamente a melhor rota para qualquer lugar.).


## Como usar
- Filtre os problemas por categoria.
- Clique em "Denunciar problema" e depois no local no mapa.
- Compare a rota mais curta com a rota segura até a escola.

## Como rodar localmente
Abra a pasta no VS Code e use a extensão **Live Server**.
(Abrir o index.html com dois cliques bloqueia o mapa.)

## Tecnologias
HTML, CSS e JavaScript puro, Leaflet.js, OpenStreetMap.

## Limitações do MVP (próximos passos)
- As denúncias ficam salvas só no navegador (passo futuro: banco de dados online).
- As rotas são demonstrativas, desenhadas à mão (passo futuro: cálculo automático por penalidade de risco).

Projeto estudantil, sem vínculo com órgãos públicos.
